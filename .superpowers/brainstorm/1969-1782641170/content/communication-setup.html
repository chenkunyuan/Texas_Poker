Server → Client
game_state完整游戏快照

⚙️ 开局配置流程
浏览器打开 → 显示设置面板
  ├─ 游戏模式: No-Limit / Pot-Limit
  ├─ AI玩家数: 2~8
  ├─ 初始筹码: 每名玩家相同
  ├─ 盲注结构: 固定 / 定时增长
  ├─ AI个性: 随机分配 / 手动指定
  └─ LLM Provider: Anthropic / OpenAI / 自定义
  ↓
点击"开始游戏" → POST /api/game/start → WebSocket连接建立 → 发牌
🎯 真人玩家可选动作
Fold 弃牌 Check 过牌 Call 跟注 Raise 加注 All-in 全押

Raise时显示滑块/输入框设定金额  |  无效动作自动灰化  |  倒计时提示
