🧠 LLM Client — Provider无关设计
LLMClient (抽象接口)
  ├─ async decide(game_context, personality) → Decision
  │
  ├─ ClaudeAdapter → Anthropic API
  ├─ OpenAIAdapter → OpenAI API
  └─ CustomAdapter → 任意兼容API
  │
  └─ 配置文件: llm_config.yaml (provider, model, api_key, params)
Prompt 结构
你是一个德州扑克玩家，风格：{personality}。
当前牌局：
- 你的底牌：{hole_cards}
- 公共牌：{community_cards}
- 底池：{pot}，当前下注：{current_bet}
- 你的位置：{position}，筹码：{stack}
- 对手行动历史：{action_history}

请分析并输出：
1. 你的牌力评估
2. 对手可能的手牌范围
3. 推荐行动：fold / check / call / raise (金额)
4. 决策理由
📼 回放系统
记录内容
  • 游戏配置快照
  • 每手牌所有玩家底牌
  • 每轮公共牌
  • 每个行动(玩家/动作/金额)
  • 底池变化记录
  • 摊牌结果
  • AI决策来源标记(规则/LLM)
回放功能
  • 逐手牌回放
  • 逐行动步进
  • 显示AI内部决策(事后)
  • 统计面板(VPIP/PFR等)
  • JSON/HTML导出

存储格式：每局一个JSON文件 → replay/2026-06-28_14-30-00.json
