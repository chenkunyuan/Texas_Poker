🤖 AI Agent 系统设计

规则引擎 + LLM增强 · 个性差异化 · 数据隔离

决策流程
轮到AI玩家
  ↓
① 收集公开信息 (公共牌、底池、位置、对手行动历史)
  ↓
② 规则引擎计算
    ├─ 起手牌范围评估 (根据位置+个性)
    ├─ 底池赔率计算
    ├─ 隐含赔率估算
    └─ 输出: {fold/check/call/raise} + 置信度
  ↓
决策确定性高? → 直接返回
  ↓ 否 (边缘决策/大底池/All-in)
③ LLM增强分析
    ├─ 构造Prompt (含个性+完整牌局上下文)
    ├─ 调用LLM API
    └─ 解析LLM建议 → 覆盖或调整规则引擎输出
  ↓
④ 最终决策 + 模拟延迟 → 返回游戏引擎

个性参数化为可配置文件，开局前随机分配或真人指定

🔒 数据隔离约束

每个AI Agent只能访问公开信息：

✅ 可访问
  • 公共牌
  • 底池大小
  • 各玩家筹码量
  • 对手公开行动
  • 当前下注额
  • 位置信息
❌ 不可访问
  • 其他玩家底牌
  • 其他AI内部状态
  • 其他AI的LLM对话
  • 牌堆剩余牌
